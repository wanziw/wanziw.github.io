# 单细胞数据处理

AnnData：scanpy标准的单细胞数据容器

> AnnData 规定“柜子有哪些”，但很多柜子里面的“抽屉叫什么名字”是分析软件和研究者决定的。

细胞*基因的表格

| 属性      | 含义                                                         |
| --------- | ------------------------------------------------------------ |
| `.X`      | 表达矩阵（行=细胞，列=基因），是核心数据                     |
| `.obs`    | 细胞层面的注释表（每行一个细胞，列=各种属性，如细胞类型、批次、QC 指标） |
| `.var`    | 基因层面的注释表（每行一个基因，列=基因名、是否线粒体基因等） |
| `.obsm`   | 细胞的降维坐标（如 PCA、UMAP 坐标），存在这里可用 `sc.pl.umap` 直接画。甚至一些模型做出来的latent representation。用adata.obsm.keys()检查。 |
| `.layers` | 字典，额外表达矩阵（例如同时保存原始 count 和 log 化后的两份）。用adata.layers.keys()检查 |
| `.uns`    | 杂项信息（调色板、邻居图参数、标记基因结果等）               |
| `.raw`    | 可选：一份「未过滤基因前的完整数据」备份                     |

```
adata
│
├── X
│   └── cell × gene 主表达矩阵
│
├── obs
│   └── 每个 cell 的信息
│       sample
│       total_counts
│       pct_counts_mt
│       leiden
│       cell_type
│
├── var
│   └── 每个 gene 的信息
│       gene_ids
│       mt
│       highly_variable
│       means
│
├── layers
│   └── cell × gene 的其他表达矩阵
│       counts
│       normalized
│       ...
│
├── obsm
│   └── cell × N
│       X_pca
│       X_umap
│       X_scVI
│
├── varm
│   └── gene × N
│       PCs 等
│
├── obsp
│   └── cell × cell
│       distances
│       connectivities
│
└── uns
    └── 什么都可以放
        分析参数
        颜色
        统计结果
        dendrogram
        neighbors 信息
        ...
```
